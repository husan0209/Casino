## 2. UI-система и роли цвета

Палитра и роли — по Части 5 §2.4, без изменений:

```
Background primary:   #0F0F1A
Background secondary: #1A1A2E
Background card:      #16213E
Border:               #2A2A4A
Accent primary:       #6C63FF   — бренд, навигация, «Играть»
Accent secondary:     #00D2FF   — редкие акценты, теги сетей, НЕ деньги
Money / Deposit:      #34C77B   — только деньги и успех (см. уточнение Ч.5 §2.4 от 2026-10-04)
Error:                #FF3D71
Warning:              #FFB300
Text primary:         #FFFFFF
Text secondary:       #8888AA
```

### Жёсткие правила витрины

1. **Один бейдж на карточку:** `NEW` или `HOT`, никогда оба.
2. **Название игры — один раз, под обложкой.** На обложке названий нет.
3. **Обложки — реальные каверы провайдеров.** Никаких градиент-плейсхолдеров с эмодзи и иконками.
4. **Зелёный — только деньги и успех.** Навигация и бренд не зелёные.
5. **Одно громкое «Играть» на экран:** кнопка на фронт-карте колоды. Плитки сетки тихие: тап = запуск, «i» = превью.
6. **Баланс + зелёная «Пополнить» — всегда в одном месте шапки, sticky.**
7. **Никаких сокращений в таб-баре:** «Избранное», не «Избр.».
8. **Таб-бар:** Главная · Казино · Избранное · Профиль. У залогиненного в табе «Профиль» — реальная аватарка, не иконка. Кошелька в таб-баре нет.
9. **Меню аватара:** Профиль · Мои кошельки · История игр · Настройки · Выйти. KYC-пункт только если статус блокирует вывод/лимит.
10. **Футер:** лого + тэглайн, 18+, Условия, Конфиденциальность, Ответственная игра, Поддержка, иконки платёжных методов текущего гео. Одна колонка на телефоне.

## 3. Тон голоса

**Принцип:** честность вместо впаривания. Короткие строки, которые звучат как человек.

### Эталоны (брать интонацию отсюда)

```
«Твой следующий большой спин.»
«Спины, которые хочется повторить.»
«Гость видит слоты. Депозит — когда сами решите.»
«12 слотов на старте. Одна зелёная кнопка, когда будете готовы.»
«Без верификации осталось 1 800 ₽»
«Платёж защищён · зачисление обычно за 1 минуту»
«В ₽ пусто. Играть с 8 200 ₸?»
```

### Капс-лейблы секций — с характером, но без каши

```
ТВОЯ ИСТОРИЯ → Продолжить играть
ВЫБИРАЙ НАСТРОЕНИЕ → Игры для тебя
СВЕЖИЕ ПОСТУПЛЕНИЯ → Новые игры
ПРОВЕРЕННЫЕ СТУДИИ → Провайдеры
```

### Запрещено на витрине

RTP, волатильность, GGR, ledger, «прибыль/убыток», обещания бонусов, которых нет. RTP и волатильность — только на превью `/casino/[slug]`.

## 4. Ключевые экраны и блоки

### 4.1 Шапка и WalletSwitcher

**Гость:** лого слева, справа `Войти` + акцентная `Регистрация` (header B).

**Свой:** лого · активный баланс с шевроном · зелёная `+` · аватарка (A/spinera).

**Тап по балансу → WalletSwitcherSheet (донор spinera):**

- группы: Фиат, затем Крипта;
- активный первым, фиолетовая рамка + чек;
- внутри группы ненулевые выше нулевых; нулевые тусклые, но видимые;
- теги сетей бирюзовым: `TRC20`, `Bitcoin`;
- внизу мягкая зелёная `+ Пополнить активный кошелёк`;
- никакой суммы «итого ≈».

**Аватарка → меню из правила 9 §2.**

---

### 4.2 Главная гостя

1. **Hero spinera:** один оффер, один CTA, стек аватарок + «N игроков уже сегодня», казино-родной фон (барабаны, монеты), лента слота внизу.
2. **GameDeck (§4.4)** без личных тегов: хайп → популярные → новые.
3. Популярные.
4. Новые.
5. Лента провайдеров.
6. Футер.

**Пустых «Продолжить играть» и «Избранное» у гостя нет.** Блок «Для новых игроков / Создать аккаунт» допустим только внизу и только гостю.

---

### 4.3 Главная своего

1. **Продолжить играть** — горизонтальный ряд карточек spinera: иконка-тайл, название, относительное время, мини-кнопка play. **Маркетингового героя НЕТ.**
2. **GameDeck** с личными тегами.
3. Чипы категорий + сетка «Популярное сейчас».
4. Один промо-слот (при выключенных флагах блок скрыт, не слайдер).
5. Новые.
6. Избранное, если не пустое.
7. Тонкая лента провайдеров.

**Блоки «Для новых игроков» залогиненному не показываются никогда.**

---

### 4.4 GameDeck — колода (новый компонент)

**Суть:** свайпаемая витрина-стек. Каждый свайп — новая игра, запускаемая сразу. Декорация становится витриной.

#### Состав и порядок

8–12 карт.

- **Свой:** твоё/последнее → хайп → новинки → популярные.
- **Гость:** хайп → популярные → новинки.

На каждой карте тег-причина: `Хайп` / `Новинка` / `Твоё избранное` / `Продолжи`. Каверы реальные, имя один раз, один бейдж. Кнопка «Играть» — только на фронт-карте.

#### Адаптив стека

- **телефон:** 1+2 (фронт + две за ним);
- **планшет:** 1+3, веер шире;
- **десктоп:** 1+3 веером + боковая кликабельная очередь следующих 4 мини-тюмбами; длина очереди адаптивная, стек всегда 1+3.

#### Матрица жестов

| Жест                        | Телефон                      | Десктоп                      |
| --------------------------- | ---------------------------- | ---------------------------- |
| Свайп/драг влево-вправо     | след./пред. карта            | то же                        |
| Тап по карте                | запуск                       | запуск                       |
| Тап по «i»                  | превью                       | превью                       |
| Двойной тап                 | в избранное, heart-burst     | клик по сердцу               |
| Драг вверх                  | **ЗАПРЕЩЁН** (отдан скроллу) | карта улетела вверх = запуск |
| Вертикальный свайп / колесо | скролл страницы              | скролл страницы              |
| Стрелки ← → / Enter         | —                            | навигация / запуск           |

#### Анимация

- **слои:** фронт наклон −3°; вторая scale 0.94 и +10px ниже; третья глубже и притушена;
- **порог свайпа:** ~1/3 ширины или флинг по скорости; уход по дуге: translateX + доворот до 12° + fade в конце;
- **вход следующей:** scale 0.94→1 с овершутом до 1.02 и возвратом, 300–350ms, пружина; haptic tick на доводке;
- **бейдж и «Играть» новой фронт-карты:** +80ms задержка, slide-up + fade;
- **обратный свайп** возвращает предыдущую карту;
- **только transform/opacity**, 60fps, предзагрузка следующего кавера;
- **prefers-reduced-motion:** кроссфейд вместо пружины, параллакс выключен.

#### Жизнь колоды

- **launch-переход:** по «Играть» фронт-карта улетает вверх и разворачивается в полноэкранный слот (cover-to-iframe);
- **shuffle:** кнопка-кубик у счётчика «4/12» — пересдача колоды с flip-анимацией;
- **контекстный BIG WIN:** плашка «+N ₽ только что» крепится к конкретной карте-виновнику и свайпается с ней, а не висит амбиентом; «сейчас играют» — тонкий бейдж на карте, не полноэкранный тикер;
- **память:** скипнутые карты уходят в хвост, повторов нет, пока не показаны все;
- **финальная карта:** «Ещё N игр в каталоге →» — свайп в неё ведёт в `/casino`;
- **автопрокрутки нет;** внизу точки/счётчик; на десктопе стрелки и hover-tilt;
- **опция:** гироскоп-параллакс слоёв на мобиле, отключается при reduced-motion.

#### Размещение

- **гость** — блок №2 после героя;
- **свой** — блок №2 после «Продолжить играть».

**Ряд «Продолжить играть» колода НЕ заменяет.**

### 4.5 GameCard и сетка

**Донор B:** обложка во весь тайл, `i` в правом верхнем углу, один бейдж в левом, название и провайдер — под обложкой, один раз.

- Сердечко — в превью, не на обложке.

### 4.7 Превью и игровой экран

По Части 5 §8:

- игровой экран: fullscreen iframe, тонкая планка `× · баланс · +`, касса оверлеем, «Вернуться в игру» после депозита, вспышка баланса на дельту, refresh после закрытия iframe.

### 4.8 Аутентификация

**LoginSheet A:**

- заголовок «Войдите, чтобы играть»;
- Google и Telegram сверху, ниже email-форма, ссылка на регистрацию;
- после успеха — продолжить launch, не выкидывать на главную;
- регистрационная форма без подтверждения пароля, с показом/скрытием и индикатором силы;
- **демо-крединшалы в проде не показывать.**

---

### 4.9 Касса

#### DepositSheet (фиат) — один экран

**Осознанное отступление от пошаговости Части 5.**

- строки методов: последний успешный первым, набор по гео+валюте; выбранный — фиолетовая рамка + чек;
- крипта при активном фиате — **ТОЛЬКО** в блоке «Ещё способы: USDT TRC20, BTC», не в первом ряду;
- сумма: AmountInput с символом валюты, пресеты активной валюты по Части 5 §2.5;
- «Минимум N ₽» и «Без верификации осталось N ₽» — всегда с символом;
- зелёная CTA «Перейти к оплате →»;
- микрокоп доверия: «Платёж защищён · зачисление обычно за 1 минуту».

#### DepositSheet (крипта)

- сеть крупно и всегда;
- «Отправьте только USDT в сети TRC20»;
- QR, адрес + копировать, дедлайн, «Проверить статус», факт зачисления.

#### WithdrawSheet

- порядок проверок Части 5 §10.3 (KYC-стопер одной кнопкой → «нечего выводить» → предложить ненулевой кошелёк);
- вывод только в валюте кошелька и на метод той же валюты;
- ConfirmModal обязателен;
- после заявки: номер, статус, «История».

## 5. Директивы по ненарисованным экранам

Ни один мок не показал эти экраны. Рисовать их в единой системе сборки, тон спокойный fintech, доноры указаны.

### 5.1 `/wallet` (страница доверия)

Активный кошелёк крупной картой: баланс, `Пополнить` / `Вывести`. Ниже группы Фиат / Крипта как в шторке spinera: тусклые нули, теги сетей. Последние 5 транзакций активного + «Смотреть все».

**Футер-строка доверия:** «Отдельные балансы. Без конвертации и скрытых комиссий.»

---

### 5.2 История транзакций `/wallet/transactions`

Мобильные карточки / десктоп таблица: дата, тип, сумма И валюта одинаково заметно, статус.

- Плюс зелёный, минус красный.
- `+1 000` без валюты = баг.

**Фильтры:** тип, валюта, период. Курс — только если реально фиксировался в крипто-платеже.

---

### 5.3 История ставок `/history`

**БЕЗ красного P/L-героя.**

Сверху чипы: ставок N, оборот в выбранной валюте, выигрыши в выбранной валюте.

**Строка:** игра, провайдер, ставка, выигрыш, дата, валюта.

Смешанный по валютам период — разбивка по кошелькам, не сумма ₽+₸.

---

### 5.4 KYC `/kyc`

Шесть состояний Части 5 §13 как продуктовые экраны.

- Лимит — в **АКТИВНОЙ** валюте.
- Визуально спокойно;
- кнопка «Пройти верификацию» только там, где статус блокирует вывод или лимит.

---

### 5.5 Поддержка `/support`

Список тикетов, создание, тред, статусы, вложения.

**Категории:** Платежи | Игры | Аккаунт | Другое.

Пустое состояние — одна кнопка «Создать тикет». **Чата в реальном времени нет.**

---

### 5.6 Рефералка `/referral`

Ссылка + код с копированием, шаги «как работает», счётчики (рефералы, активные, заработано, доступно), вывод в выбранный кошелёк, история начислений, список без полных email.

**Формулировка:** «бонус с игры друзей».

**Слова GGR и «процент с проигрышей» запрещены.**

---

### 5.7 Профиль `/profile`

Шапка: аватар, email, KYC одной спокойной строкой, дата регистрации.

**Вкладки:** Данные · Безопасность · Сессии · Настройки.

- **Сессии:** IP, устройство, дата, завершить одну / все кроме текущей.
- **OAuth-аккаунт** без формы смены пароля, с пояснением.

---

### 5.8 Поиск `/search`

Недавние запросы, last played, пустой результат → похожие слоты + сброс.

---

### 5.9 Избранное `/favorites`

Сетка GameCard.

**Пусто** → 6 популярных + «В каталог».

---

### 5.10 Провайдер `/providers/[slug]`

Те же карточки, заголовок провайдера + счётчик игр, без отдельного визуального языка и без дублей плиток.

---

### 5.11 Десктоп

- Икон-панель 64–72px слева;
- поиск в хедере + ⌘K;
- сетка 5–6 колонок;
- GameDeck 1+3 + очередь;
- касса оверлеем;
- порядок денег тот же.

**Тултипы только здесь.**

## 6. Don't-лист (баги моков + Части 5 §24)

### Из моков — не повторять никогда

- ❌ дубль названия на карточке (на обложке и под ней) — баг A и spinera;
- ❌ градиент-плейсхолдеры с эмодзи вместо каверов — A, spinera;
- ❌ два поиска подряд на каталоге — B;
- ❌ обложка не совпадает с подписью (Mystic Gems под Dragon Pearls) — B;
- ❌ дубль одной плитки на странице провайдера — B;
- ❌ «Избр.» в таб-баре — B;
- ❌ футер без 18+ и платёжных иконок — spinera;
- ❌ меню аватара без «Истории» — spinera;
- ❌ USDT третьей строкой в ряду с фиат-методами — spinera;

## 7. Приёмка сборки

- [ ] Гость за 10–15 секунд понимает: куда нажать, что можно играть без регистрации, где деньги.
- [ ] У залогиненного первый экран — «Продолжить играть», не маркетинг.
- [ ] Колода свайпается обеими сторонами, launch-переход «карта вверх» работает, драг вверх на таче не перехватывает скролл.
- [ ] В шапке одна сумма; switcher показывает 7 кошельков, нули тусклые; суммы «итого» нет.
- [ ] Депозит: один экран, крипта в «Ещё способы», пресеты и минимумы в активной валюте, KYC-остаток с символом.
- [ ] Казах не видит СБП первым; роуминг не сбрасывает казахстанскую кассу.
- [ ] На карточке имя один раз, один бейдж, кнопка «Играть» только на фронт-карте колоды.
- [ ] Футер: 18+, платёжные иконки гео, тэглайн.
- [ ] Ни один экран не показывает сумм без валюты и не суммирует ₽+₸+USDT.
- [ ] reduced-motion: колода кроссфейдит, параллакс выключен.
