# User Flow — первые 90 секунд

> **Это не новое ТЗ.** Это путь человека. Контракт для приёмки UI и кассы.  
> Технические детали: [tz-part-5](tz-part-5-frontend-web.md), платежи: [tz-part-3](tz-part-3-payments-wallet.md) §15.

---

## Тайминг

| Интервал | Что должно произойти |
|---|---|
| **0–15 сек** | Понял, куда попал; нажал на слот |
| **15–45 сек** | Вошёл или зарегистрировался |
| **45–90 сек** | Крутит демо **или** уже в кассе |
| **Первый спин на деньги** | После оплаты — скорость кассы/PSP, не UI |

Для рекламного трафика цель не «красиво походить по сайту». Цель: **слот → вход → касса** без лишних экранов.

---

## Кто приходит

Почти всегда телефон, почти всегда из рекламы, Telegram или реф-ссылки.

В голове 3 вопроса:

1. Это казино, тут можно играть?
2. Есть игра, которую я узнаю?
3. Как пополнить *моими* деньгами?

Всё остальное на первых 90 секундах — шум: KYC, рефералка, RTP, 5 кошельков, Live, бонусы которых нет.

---

## Сценарий 1. Новый человек с рекламы — главный

Допустим: Россия, RUB, телефон, никогда не был.

### 0:00 — открыл ссылку

**Что видит:**

- тёмный экран казино, не лендинг с простынёй;
- в шапке: лого, **Войти**, **Регистрация**;
- один понятный баннер *или сразу слоты*;
- сетка знакомых игр: Sweet Bonanza, Dog House, Book of… — не абстрактные «наши эксклюзивы».

**Что не видит:**

- выбор страны;
- выбор валюты;
- «проверьте email»;
- Live / Crash / Быстрые;
- крипту на первом экране;
- 3 слайда акций.

Гео сработало тихо: валюта в голове уже ₽, даже если он ещё не вошёл. Пресеты и касса потом будут рублёвые.

> Если за 3 секунды не видно слотов — человек закроет.

### 0:08 — скроллит пальцем

Ищет обложку, которую узнаёт. Поиск уже есть, но новичок из рекламы им почти не пользуется. Сначала картинки.

Полка «Продолжить играть» пустая — **её нет**. Не заглушка.

### 0:12 — тап по обложке

Не страница игры. Не «Играть / Демо».  
**Тап = хочу запустить.**

Открывается **LoginSheet** снизу:

```text
Войдите, чтобы играть

[ Google ]
[ Telegram ]

или

email
пароль

Нет аккаунта? Создать
```

Заголовок про игру, не про «добро пожаловать в экосистему».

### 0:20 — регистрация

Самый короткий путь: **Telegram или Google**. Для рекламы в СНГ это важнее email.

Если email:

- почта;
- пароль;
- галочка с условиями.

**Нет:** повтора пароля, поля «реферальный код» (если `?ref=` уже есть — подставить тихо), captcha с первого раза, обязательного телефона, выбора валюты и страны.

Нажал «Создать» → **сразу сессия**. Письмо ушло фоном. Человека не выкидывать на «проверьте почту».

> Если после регистрации снова главная и надо заново искать слот — вы потеряли его.  
> После входа **продолжить ту же игру**.

### 0:35 — игра почти открылась, денег нет

Он новый, все кошельки пустые.  
**Не показывать** выбор из ₽ ₴ ₸ USDT BTC.

Сразу **DepositSheet** в ₽:

```text
Пополнить ₽

СБП                         последний/первый
Карта
P2P
Ещё способы

Сумма
[ 2 000 ] ₽
[1 000] [2 000] [5 000] [10 000]

Минимум 500 ₽
```

Один вопрос: сколько и чем.  
Не «фиат или крипта». Крипта внутри «Ещё».

### 0:50 — выбрал СБП, нажал Пополнить

Ушёл в банк / PSP. Это уже не ваши 90 секунд. Тут конверсия зависит от кассы, не от красоты кнопок.

Когда деньги пришли:

```text
+2 000 ₽ зачислены
[Вернуться в игру]
```

Шапка: `2 000 ₽` и зелёная «Пополнить».  
Игра открывается в ₽, без вопроса «с какого кошелька».

### ~после оплаты — первый спин

Планка над слотом:

```text
×     2 000 ₽     [+]
```

`+` снова открывает кассу поверх игры, не уводит на `/wallet`.

**На этом путь новичка закончен.** Он в зале.

## Где отваливаются

Считайте эти места дырками, не «потом поправим».

| Момент | Если сделать плохо | Человек |
|---|---|---|
| Первый экран | долго грузится, пусто, слайдер 5 сек | закрыл |
| Карточка | тап открыл статью про RTP | потерялся |
| Вход | редирект на `/login`, слот забыли | не вернулся |
| Регистрация | «подтвердите email» | ушёл в почту и не пришёл |
| После входа | снова витрина, игра сброшена | устал |
| Пустой баланс | выбор из 5 валют | не понял |
| Касса | СБП и Kaspi и USDT в одном ряду | думает, сайт не его |
| Оплата ок | «Закрыть» на кошелёк | не нашёл игру |
| Нулевой спин | ошибка «insufficient funds» тостом | не знает, что делать |

Каждый из этих пунктов важнее цвета кнопок.

## Сценарий 2. Тот же новичок, другой geo

Путь тот же. Меняется только тихая часть.

| Geo | Что меняется |
|---|---|
| **KZ** | Шапка в ₸, Kaspi и локальные методы, не СБП |
| **UZ** | Длинные суммы: `100 000 soʻm`, не `100000` |
| **BY** | BYN, не «белорусские рубли как RUB» |
| **UA** | Только украинские методы; российских в списке нет |

Человек **не выбирает страну**. Если IP врёт — потом сменит кошелёк в шапке. Не на первом шаге.

**Ошибка:** показать узбеку пресеты `500 / 1000 / 2000` как будто это рубли.

> MVP платежи: RUB + USDT + BTC. Остальной фиат — Phase 2 ([tz-part-5](tz-part-5-frontend-web.md) §2.2); flow тот же, меняются методы и пресеты.

## Сценарий 3. Сначала демо без денег

Не главный рекламный путь, но нельзя прятать в подвал.

**Как попадает:**

- тап по `i` на карточке → **Демо**;
- или на странице игры кнопка «Демо».

Демо **без регистрации**. Через 20–40 секунд видит барабаны.

После 1–2 демо-спинов **не** выпрыгивать попапом «зарегистрируйтесь!!!». Когда сам нажмёт «Играть» — тогда LoginSheet.

- **Telegram/контент** — демо полезнее для прогрева.
- **Горячая реклама** — сразу деньги, как в сценарии 1.

В релизе бонуса нет → на баннере нельзя «+100%».

## Сценарий 4. Свой игрок, следующий день

0:00 — открыл, уже в сессии. Шапка: `1 200 ₽  [Пополнить]`  
0:03 — первым **Продолжить играть**, не hero  
0:06 — тап по вчерашнему слоту  
0:08 — игра сразу, без выбора валюты и страницы описания

Если ₽ кончились, а в ₸ есть 8 200:

```text
В ₽ пусто
Играть с 8 200 ₸?
[Играть в ₸]   [Пополнить ₽]
```

Два решения, не пять кошельков.

Если везде ноль — сразу касса в **последней** валюте.

**Цель для своего: спин за 10 секунд.**

## Сценарий 5. Крипта в первые 90 секунд

Для массы СНГ — не первый путь. QR на главную не ставить.

1. Тап → вход → касса в ₽/₸  
2. Не видит свой метод / не хочет фиат  
3. **Ещё способы → USDT TRC20**

```text
Только USDT · только TRC20
QR + адрес
ждём оплату
```

После зачисления: активный кошелёк USDT, «Вернуться в игру», слот в USDT **только если провайдер умеет**.

Если не умеет — без тихой конвертации в ₽:

```text
Эта игра не работает в USDT
Можно сыграть с ₽, если пополните
[Пополнить ₽]   [Другая игра]
```

BTC — только после «Ещё способы».

---

## Что в голове через 90 секунд

Новичок после удачного пути помнит:

- я в казино;
- вот слоты;
- вот мои деньги в шапке;
- вот зелёная кнопка пополнить;
- вчерашняя игра будет наверху.

Не обязан помнить: KYC, BYN, TRC20, вейджер, провайдер, рефералка.

---

## Два продукта в одних 90 секундах

| Трафик | Путь |
|---|---|
| **Горячий (реклама «играть»)** | Слоты → вход → касса. Демо не мешает, но не главный CTA |
| **Свой / вчерашний** | Продолжить играть → слот. Касса только если деньги кончились |

Герой-баннер — гостю. Своему каждый день мешает.

---

## Минимальный скрипт (чеклист приёмки)

```text
Гость, телефон, реклама:
открыл → увидел слоты → тап по игре → LoginSheet →
Google/Telegram/email → сразу тот же слот →
денег нет → DepositSheet в валюте гео →
оплата → Вернуться в игру → спин.

Нельзя:
страна, валюта, письмо-тупик, сброс игры после логина,
5 кошельков, крипта первой, Live, бонус которого нет.

Свой:
открыл → Продолжить играть → слот за 10 секунд.
```

## Backend: что должно успеть за те же 90 секунд

См. [tz-part-3](tz-part-3-payments-wallet.md) §15 — контракт API для кассы.

Кратко:

| Шаг | API / поведение |
|---|---|
| Гость открыл сайт | `GET /geo/config` → defaultCurrency, methods без auth |
| После login + пустой баланс | `GET /geo/config` + `currency_preference` → только методы этой валюты/гео |
| DepositSheet | `GET` presets/min из geo + currency; `POST /deposit/fiat` с `method` + `currency` |
| Успех оплаты | polling/webhook → wallet credit → фронт: pending game slug из UIStore |
| Launch | `POST /games/:slug/launch` с валютой активного кошелька, без конвертации |
